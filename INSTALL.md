# 0xmfbk GitHub Profile Kit

## Install
1. Create or open the repository named **`0xmfbk`** (the repository name must match your GitHub username to act as the profile README).
2. Upload `README.md` to the repository root.
3. Upload the whole `assets/` folder without changing its name; the README references `./assets/hero.svg` and `./assets/boundary-map.svg`.
4. Commit the changes. GitHub will render the README on your profile page.

## Before publishing
- Confirm the project description and social/donation URLs are still current.
- Optional: remove any technologies in the expandable inventory you do not want associated with your profile. The list was reorganized from the supplied sample.
- Statistics, streak, activity, trophy, typing, badge, and visitor-counter images use third-party hosted services; they may occasionally be unavailable or change behavior.

## Files
- `README.md` — complete profile README.
- `assets/hero.svg` — custom cyber-research hero banner.
- `assets/boundary-map.svg` — custom conceptual research map.
